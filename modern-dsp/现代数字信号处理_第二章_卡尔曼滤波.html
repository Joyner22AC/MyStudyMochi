学习主线与习题讲解第二章习题：Kalman 与状态空间

Kalman：每来一帧新观测，就把旧信息压缩并更新

它解决的是动态估计：目标状态看不见、随时间变化；传感器每一时刻给出带噪观测。Kalman不保存所有历史样本，而保存“当前估计 + 对它有多不确定”。

  1. 第一步：分清隐藏状态和传感器读数

    状态 s(n) 是真正关心的量，观测 x(n)=Hs(n)+v(n) 是带测量噪声的读数；状态方程描述目标如何运动/演化。应用例：用带噪位置测量估计目标位置和速度。

    若没有状态模型，只能把观测当静态数据；算法不知道状态下一拍应该怎样变化。

    用 F 和过程噪声 w 表示状态转移及未建模扰动。

  2. 第二步：先验预测与不确定度传播

    由上一时刻后验估计乘 F 得到先验状态；协方差通过 FPFᵀ 加过程噪声 Q 得到。均值告诉“预计在哪”，协方差告诉“预计错多少”。Q越大，表示模型对真实变化越不自信。

    只预测不校正，误差会受模型偏差和扰动不断累积，无法利用新传感器读数。

    把观测预测与真实观测相减，形成创新；它是观测里尚未被模型解释的部分。

  3. 第三步：创新只保留新来的信息

    创新 ν=x−Hŝ⁻，创新协方差 S=HP⁻Hᵀ+R。若创新长期偏离零、方差远超预测，可能是模型/噪声设定错误或出现异常工况。创新也能用于一致性诊断。

    创新本身不是最终估计；仍要决定它相对先验应占多大权重。

    Kalman增益按先验不确定度与观测噪声协方差做最优加权。

  4. 第四步：增益决定信模型还是信观测

    K=P⁻HᵀS⁻¹，后验=先验+Kν。R大（观测嘈杂）时K通常变小；P⁻大（模型预测不准）时K通常变大。更新后再缩小/修正协方差，供下一帧使用。

    公式不能代替建模：错误的F/H/Q/R、不可观测状态、非线性强或异常值会造成偏差甚至发散。

    检查维度、协方差半正定、创新统计与可观测性；非线性场景需评估扩展/无迹Kalman或粒子滤波。

  5. 最后判断适用范围，而非只会代公式

    线性系统、零均值白噪声且协方差已知时，标准Kalman最清楚；噪声高斯时它还是条件均值最优。非高斯但二阶统计相同，它仍是线性MMSE解，不一定是所有估计器中的全局最优。

    与Wiener的关系：稳态、统计量固定的线性系统中，Kalman递推可能收敛到固定增益，与因果Wiener滤波等价；前者利用状态模型递推，后者从统计结构直接求解。

一帧的闭环：上一帧后验 → 状态预测 → 创新 → 按不确定度加权 → 新后验。考试作答时也按这个顺序写，说明每个量的时间下标和先验/后验身份。

第二章习题：Kalman 与状态空间

1｜比较 Wiener 与 Kalman

书 p.60 · PDF 第69页

考查目标与所用知识
对应本页第1–8节与 Wiener 笔记第10节。

规范解答
共同点：线性最小均方估计，最优条件最终都可写成误差正交。差别：Wiener 通常一次求固定滤波器，要求统计量已知；Kalman 用状态空间模型逐时刻预测—更新，显式传播误差协方差。线性高斯时 Kalman 还给出条件均值意义下的最优估计。

结果检查与迁移
不是“一个频域、一个时域”这么简单；核心区别是静态批量解 vs. 状态递推，以及两者依赖的信息组织方式。

5｜把两组差分方程改写成状态方程

书 p.60 · PDF 第69页

考查目标与所用知识
题目给两组输入—输出差分方程，要求各自写状态方程与输出方程。这里直接选“延迟输出+延迟输入”为状态，避免套矩阵模板时漏掉输入延迟或直通项。

规范解答
(1)令ξ₁(n)=[y(n−1),y(n−2),y(n−3),y(n−4),x(n−1),x(n−2),x(n−3),x(n−4)]ᵀ，u(n)=x(n)。由原式解出y(n)=0.5y(n−1)+0.49y(n−2)−0.125y(n−3)−0.06y(n−4)+x(n−1)−0.3x(n−2)−0.06x(n−3)+0.008x(n−4)。输出方程即此式；状态更新为ξ₁(n+1)=[y(n),y(n−1),y(n−2),y(n−3),u(n),x(n−1),x(n−2),x(n−3)]ᵀ。(2)令ξ₂(n)=[y(n−1),y(n−2),x(n−1),x(n−2)]ᵀ、u(n)=x(n)。输出方程y(n)=0.9y(n−1)+0.2y(n−2)+u(n)+x(n−1)；状态更新ξ₂(n+1)=[y(n),y(n−1),u(n),x(n−1)]ᵀ。两组式子均是显式的状态空间实现，逐项移位即可读出A、B、C、D。

结果检查与迁移
把每个状态分量按定义向前移一拍，确认更新后状态仍等于所定义的历史量；将输出方程代回原差分式，(1)没有当前输入直通项，(2)有D=1。状态实现不唯一，但输入输出关系必须一致。

6｜由状态方程求系统函数和差分方程

书 p.60 · PDF 第69页

考查目标与所用知识
对应第7节：状态空间到传递函数的标准映射。

规范解答
对 x(n+1)=Ax(n)+Bu(n)、y(n)=Cx(n)+Du(n)，H(z)=C(zI−A)⁻¹B+D。按扫描读到 A=[[2,1/2],[0,1]]、B=[4,4]ᵀ、C=[1,0]、D=1，得 H(z)=z(z+1)/[(z−1)(z−2)]=(1+z⁻¹)/(1−3z⁻¹+2z⁻²)，故 y(n)−3y(n−1)+2y(n−2)=x(n)+x(n−1)。

结果检查与迁移
一定保留 D=1 的直通项；结果可代回分子/分母复核。

7｜AR(1) 隐状态的估计与预测

书 p.60–61 · PDF 第69–70页

考查目标与所用知识
本题的滤波部分接 Wiener；状态递推部分对应本笔记的预测、创新、增益和协方差。

规范解答
统一采用题面 x(n)=s(n)+v(n)、F=0.6、H=1、Q=0.82、R=1。稳态预测误差方差 P⁻=1，K=0.5；状态估计为 ŝ(n|n)=0.5x(n)+0.3ŝ(n−1|n−1)，对应传函 0.5/(1−0.3z⁻¹)。若题目(2)令 v=0，则 x=s，过去样本的一步预测为 ŝ(n|n−1)=0.6x(n−1)，即 0.6z⁻¹。
