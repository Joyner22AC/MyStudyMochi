# MyStudyMochi

> 把零散资料，慢慢揉成容易消化的知识。

一个简约、持续生长的中文学习空间：从多源资料出发，把公式、图示和前后知识关系整理成能读懂、能复习的笔记。

[打开学习主页 →](https://joyner22ac.github.io/MyStudyMochi/)

## 阅读体验

- 日间与夜间主题
- 可折叠目录、回到顶部和适配手机的阅读布局
- 课程笔记按知识脉络组织；公式尽量交代来由、条件与用途
- 书架阅读器支持目录、翻页、书签、字号调整和进度恢复
- 主页材质离线渲染，提供自动、细致、像素和简化模式；手机默认加载轻量纹理，纹理失败不阻塞操作
