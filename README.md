# MyStudyMochi

> 把零散资料，慢慢揉成容易消化的知识。

一个持续生长的中文学习空间，也是一间可以慢慢探索的书房。这里有按知识脉络整理的学习笔记、需要密钥解锁的私人书架，以及能拿起手稿、翻开活页夹、留下学习便签的拟物化桌面。

**[进入学习主页](https://joyner22ac.github.io/MyStudyMochi/) · [体验实时三维书房](https://joyner22ac.github.io/MyStudyMochi/desk-live-preview/) · [打开我的书架](https://joyner22ac.github.io/MyStudyMochi/bookshelf/)**

## 一张书桌，一柜书

书房的视觉方向结合了 Mid-Century Modern（美式复古现代主义）、木质家具、纸张与黄铜物件。希望打开学习资料的过程，也有一点坐下来读书的仪式感。

实时三维书房目前是独立体验入口，原学习主页继续保留。场景中的物件承担实际操作，视角移动、取物和归位在同一个空间里连续完成。

| 物件 | 可以做什么 |
| --- | --- |
| 桌面手稿 | 取起课程笔记，展开阅读，合上后放回书桌 |
| 课程活页夹 | 从书架取夹、展开章节，取页阅读后回夹归架 |
| 私人书柜 | 使用密钥开锁、打开柜门、抽书阅读，退出后归位；当前页面内可反复取阅 |
| 台灯与控制台 | 调整开关、亮度和冷暖；物件音效默认关闭，可自行开启 |
| 抽屉 | 查看最近阅读卡片，回到上次的课程与阅读位置 |
| 学习便签 | 记录待办或疑问、关联课程章节、安排日期、自动保存，支持完成标记与删除撤销 |
| 学习台历 | 按日期回顾读过的章节；学懂后手动标记完成，手机上可展开或收起月历 |

鼠标悬停、触屏和键盘都有对应入口；右上角“学习”可以直接打开便签与台历。设备无法显示三维场景时，可使用已加载的学习工具或回到原主页。真实设备的触控、性能与阅读舒适度仍在持续打磨。

## 学习内容

笔记以课程资料为主线，尽量补齐概念之间的联系、公式的适用条件与推导步骤，并保留有助于核对的来源信息。它们会随学习和反馈修订，欢迎指出错误或遗漏。

| 课程 | 主要内容 | 入口 |
| --- | --- | --- |
| 毫米波雷达基础 | FMCW 距离、相位、速度、系统设计、角度、检测与跟踪 | [开始学习](https://joyner22ac.github.io/MyStudyMochi/mmwave-radar/) |
| 现代数字信号处理 | 随机信号、谱估计、Wiener 滤波、预测、Kalman 与 LMS | [开始学习](https://joyner22ac.github.io/MyStudyMochi/modern-dsp/) |
| 阵列信号处理 | 阵列模型、方向图、空间统计、CBF、Capon / MVDR 与 MUSIC | [开始学习](https://joyner22ac.github.io/MyStudyMochi/array-signal-processing/) |
| 高等工程数学 | 线性空间、线性变换、特征结构与内积空间 | [开始学习](https://joyner22ac.github.io/MyStudyMochi/advanced-engineering-math/) |
| 现代信号处理 | 信号描述、统计与变换、采样硬件和信号恢复 | [开始学习](https://joyner22ac.github.io/MyStudyMochi/modern-signal-processing/) |
| 毫米波雷达系统解析 | 硬件接口、固件数据流与算法代码；需密钥进入 | [打开学习空间](https://joyner22ac.github.io/MyStudyMochi/radar-board/) |

## 阅读与记录

- **课程笔记**：日间 / 夜间主题、可折叠目录、回到顶部、手机布局；部分课程提供知识串联与习题讲解侧栏。
- **教材对照**：已接入的教材和手册可以在独立滚动、可调宽的侧栏内阅读；受保护资料需要对应密钥。
- **电子书**：独立阅读区支持分页 / 连续阅读、分页模式滚轮翻页、目录、字号与排版偏好、书签、划线标记和进度恢复。当前书架收录《正义之心：为什么人们总是坚持“我对你错”》。
- **学习记录**：便签、台历、书签、划线和阅读进度保存在当前浏览器，不跨设备同步。便签最多保留 100 张，台历保留最近 3650 条阅读记录；清理网站数据可能清除本机记录。

台历记录从功能启用后开始。“打开过”只表示访问过该章节，是否学会由使用者自己判断并标记。
